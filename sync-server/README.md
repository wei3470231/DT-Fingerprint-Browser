# DT 云同步服务

服务端使用 Python 3.10 或更高版本，支持 Linux 和 Windows。使用标准库，无需安装 Python 依赖。

在项目根目录启动：

```sh
python sync-server/server.py --data-dir ./sync-data
```

Linux 如果 Python 命令为 `python3`，用 `python3` 执行上面的命令。服务默认监听 `0.0.0.0:55550`，也可以通过 `--host` 和 `--port` 修改。

在服务端电脑打开 `http://127.0.0.1:55550/admin`，逐个添加团队密钥。密钥支持 1～64 个小写英文字母、数字、短横线和下划线，以字母或数字开头。Windows 保留目录名不能作为密钥。

点击任意密钥旁的 **查看备份**，可查看该密钥保存的环境、分组、内核、上传时间和大小。点击 **下载备份** 保存原始 `.dt-sync.gz` 文件。旧版整套备份可以展开查看其中的环境，下载后可在客户端的 **本地备份** 中选择一个环境恢复。

每把密钥的备份存到 `sync-data/<密钥>/`。同名环境各自保留最近四份按环境上传的备份，`sync-data/sync.sqlite3` 记录密钥和版本索引。升级服务端时，停止旧进程，替换脚本后用原数据目录启动。旧版整套备份会出现在新版云端列表中，可单独取出其中一个环境。迁移或备份整个服务时，先停止服务，再复制整个 `sync-data`。

管理页只接受服务器本机的连接。Linux 服务器没有桌面时，可用 SSH 将管理端口转发到管理电脑：

```sh
ssh -L 15550:127.0.0.1:55550 user@server
```

然后在管理电脑打开 `http://127.0.0.1:15550/admin`。客户端可以通过内网访问同步接口。

## 浏览器设置

1. 打开 DT 指纹浏览器的 **系统设置 → 云同步**。
2. 填入服务端 IP 和自己的密钥。密钥在输入框内直接显示，点击底部 **保存并应用设置** 后会在下次打开时自动填入。输入裸 IP 时会使用端口 `55550`，也支持指定端口和填写 HTTPS 地址。
3. 展开 **上传备份**。可勾选单个或多个环境、全选，或切换到按分组上传。关闭所选环境，点击 **上传备份** 即可。
4. 点击 **选择云端环境** 会刷新列表。选择环境和时间，点击 **同步所选环境**。同名环境在确认后覆盖，新环境直接添加。同步保留其他环境，无自动本地备份。
5. 展开 **本地备份**，可手动导出 `.dt-sync.gz`，也可以选择本地或从服务器手动复制的备份文件，再恢复文件中的指定环境。旧版在本机生成的整套备份仍可在 **恢复旧版全量备份** 中选择。

备份包含环境设置、指纹、UA、分组、Cookie 和浏览历史，以及 Chromium 已保存的标签页会话。正常关闭 Chromium 后再上传，目标环境首次常规启动时恢复这些标签页。Electron 从启用历史记录功能的版本起记录访问历史。全局设置、管理器书签、同步连接、网页缓存、站点存储和内核文件留在本机。若扩展或代理文件使用旧设备的绝对路径，可能需要在新电脑重新选择。

两种内核使用各自的接口读写 Cookie。浏览器关闭后已经失效或已清除的会话 Cookie 可能需要重新登录。保存在快照中的有效会话 Cookie 会在恢复后首次启动相应环境时加载。Chromium 原配置未开启调试端口时，该次启动会临时使用随机的本机回环端口。

## 本机验证

```sh
node scripts/test-cloud-sync.js
```

脚本使用临时 Python 服务及独立资料目录，验证密钥隔离、管理页列表与下载、按环境及分组上传、旧版备份、同名覆盖与新增、本地备份、双内核 Cookie 和 Chromium 标签页恢复。运行需要已有 Electron 和 Chromium 开发内核及 `python` 命令。
